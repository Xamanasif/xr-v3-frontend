# XR Learning Platform V3 — frontend review and feedback register

For recording stakeholder feedback on the V3 frontend (commit `4c0f180`). **Nothing recorded here
is implemented automatically**: every change needs review and explicit authorisation first. A
spreadsheet copy of the template is `FRONTEND-REVIEW-REGISTER.csv`.

## How to record a comment

| Field               | Meaning                                                                                                                                                                                                                           |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ID                  | FB-001, FB-002 …                                                                                                                                                                                                                  |
| Area                | Public Landing & Catalogue · Entry & Shared · Super Admin · Vendor · Academic Reviewer · Content Manager · Institute Admin · Faculty · Student · Cross-role workflow · Responsive · Usability & accessibility · Business decision |
| Screen or workflow  | e.g. “IA-05 Give students access”, “Vendor → Reviewer return”                                                                                                                                                                     |
| Feedback            | What the stakeholder said, in their words                                                                                                                                                                                         |
| Type                | Visual issue · Functional issue · New requirement · Clarification                                                                                                                                                                 |
| Severity / priority | P1 must change before approval · P2 should change · P3 could change · Info                                                                                                                                                        |
| Proposed resolution | What would change (no implementation yet)                                                                                                                                                                                         |
| Decision owner      | Who decides (Owner, PM, BITS academic, …)                                                                                                                                                                                         |
| Approval status     | Open · Approved for implementation · Rejected · Deferred (post-freeze) · Done                                                                                                                                                     |
