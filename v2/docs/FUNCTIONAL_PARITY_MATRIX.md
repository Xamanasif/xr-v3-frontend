## I · v46 amendment (12 October 2026)

The v46 frontend is built on typed mock services before the backend (`MIGRATION_STRATEGY.md` §8). The status `Web (mock)` (header table) tracks that work separately from the parity ladder above; no row's status is changed by this amendment.

The audit found that **26 of the 36 rows conflict wholly or partly with v46** (`docs/v46/understand/functional-prototype.json` `parityMatrixNotes`, 28 notes). The gold-standard rules are not deleted and no stakeholder decision is resolved here: where v46 follows an owner binding constraint, the frontend follows it; where the conflict is a stakeholder ↔ v46 question, it stays open in `docs/v46/audit/Appendix-G-Owner-Decisions.md` §C.
