# @xr/domain

Pure business rules and vocabularies. No framework, no I/O, no persistence.

Phase 0 contents are deliberately small: the seven-role vocabulary, the technology enum, the
runtime-event vocabulary and the technology-specific simulation-completion derivation — the
first **worked example** of how gold-standard rules migrate (`docs/MIGRATION_STRATEGY.md` §3,
parity row P-13). Every rule cites its governing decision and the gold-standard function it was
transcribed from. The rest of the state engine is migrated slice by slice in Phase 2.
