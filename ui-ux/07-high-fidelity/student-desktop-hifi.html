STATE-01 · Access restricted

Four variants, each naming who can resolve it — because the Student cannot. No purchase prompt in the licence-cap variant: a B2B Student cannot buy past their institution's cap. Internal authorization codes are never exposed (C-07). Note that a module locked by sequence is deliberately not here — that is a normal state handled in place on STU-03/STU-04, not a failure page.

STATE-03 · System error

The third distinct failure class: the platform failed, not the Student's access and not the content. Kept separate because the cause, the wording, and the recovery path all differ. Design-supplied — no FRD requirement defines error handling; it exists because D-18 obliges every failure to say what happened and what to do next.
