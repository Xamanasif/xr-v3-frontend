QA utility — stores a partial prototype-state patch (deep-merged over the demo state on next load; versions, requests, platformRoles and instOrder are replaced wholesale so an "everything settled" or "no institutions" seed is expressible), then opens the Batch 05 prototype at the requested route. Usage: qa-seed.html?f=seed-states/<file>.json&reset=1#/route. Requires an http server (fetch does not run from file://).
