Queue
One row per written answer waiting, oldest first; filters by assessment and state. Mark next opens the oldest.
Mark page
AR-4: the question, the student’s answer and the free-text marking guidance on the left; the mark and feedback on the right. Choice questions show as “Marked automatically”.
Rules
Mark required, whole number from 0 to the question’s marks. Feedback optional (open — see B4-16). Save mark keeps it editable; Confirm marks (DL-1) makes it read-only.
After confirming
Confirmed marks can’t be changed — re-marking is not designed (T-20). The panel says when the student will see the result, per the assessment’s release setting.
Not designed
Suggested marks from an assistant (T-23 — WAIT), a rubric builder (T-21: free-text guidance only), messages to the student (T-34).
No Faculty marker
When a course has no Faculty, its written answers can’t be marked and the Institute Admin is warned on their Overview (frame below — a new state of an approved Batch-2 screen, drawn here; B2-01 is unchanged).
