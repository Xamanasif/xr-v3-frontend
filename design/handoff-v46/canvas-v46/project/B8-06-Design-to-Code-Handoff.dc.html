Batch 8 · Design-to-code handoff index

Handoff to Claude Code

Everything Claude Code needs to build the connected XR Learning Platform from the approved designs — without re-inventing the visual system. This batch prepares the handoff; it does not start the React application.

React · Next.js · TypeScript (to be built in a separate phase)Package: project/handoff/Visual authority: Batches 0–8 boards

What Claude Code builds

Claude Code implements (not designed here)Requirement
AppReact · Next.js (App Router) · TypeScript. One product, one shell, one router; a sidebar item exists only when its screen exists.
Shared stateOne application store for every record in B8-07, so a decision in one role’s screen is what every other role sees. Board controls are NOT product features.
Mock servicesTyped service interfaces for requests, institutions, access, people, progress, feedback, assessments, marking, submissions, publication, corrections, structure, roles, operations — returning the sample world. Real auth, payment, XR runtimes, grading automation and persistence stay out until decided.
PermissionsRole guards per workspace (XS-06 “Not your workspace”); actions offered only where the design offers them (e.g. no Publish for the Super Admin, approve-only device transfers).
ValidationExactly the rules drawn: required reasons on DL-2 actions, field errors + error summary, duplicate checks where shown (codes, names, scopes).
TestsFlow tests A–F and the device chain across roles; accessibility (keyboard, focus return, labels); responsive at 1440 / 1024 / 768 / 375; a real-pointer reach test for every confirm button (the Batch-4 lesson).
Not to copyBoard controls, captions, annotations, sample-data labels, the canvas frames themselves, and the rejected Slice-1 UI.

tokens.json · tokens.cssDesign tokens extracted from xr-foundation.css (unchanged values).
open-decisions.jsonEvery open decision with its safe treatment and classification (B8-08).
assets.jsonReal assets vs placeholders.
files.jsonEvery deliverable file with its md5 and its role (board · stylesheet · art · data).

The boards stay the visual authority; the JSON files index them. Where a board and a file differ, the board wins and the difference is a defect to report.
