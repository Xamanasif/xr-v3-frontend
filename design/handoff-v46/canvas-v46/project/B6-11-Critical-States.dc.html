Never confuseHow the screens keep them apart
Approve vs PublishThe Academic Reviewer’s Approve says “does not publish”; only the Content Manager’s decision page has Publish.
Publish vs accessPublish says once that it gives no one access. Institution access, Faculty mapping, Student access, simulation activity and completion are other flows (Batches 1–4).
Publish vs Release“Publish” never appears on the correction path. Corrections end with the Super Admin’s Release / Hold (Batch 7).
Edit vs liveEvery edit to published content is a correction draft; “Live · read-only” on the published experiment; “Live version 1.2 unchanged” on every update.
Return vs rejectThere is no Reject. Returns always carry a reason and go to a named person: Vendor, Academic Reviewer or Content Manager.
