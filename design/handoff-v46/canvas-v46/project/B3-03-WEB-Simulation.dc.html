How it works

Question
“Start or continue the web simulation.”
One large action
Launch WEB (not started) · Continue WEB (in progress) · Give feedback on WEB (completed). Opens in a new tab; this page keeps the status.
Failure
“The simulation didn’t open. Nothing was lost.” + Try again · Report a problem (Help, Batch-0 board 07).
Completion
Only an event reported by the simulation sets “Completed (date)” — the completion contract is OPEN (T-12 / A-06); no self-report control. What exactly “last saved” records comes from the simulation.
Not designed
Any simulation imagery or runtime screen (no fabricated XR / runtime evidence, §V-18).
