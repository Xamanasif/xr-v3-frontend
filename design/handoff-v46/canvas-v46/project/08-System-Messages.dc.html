Rules
  • One H1 per message page; never repeat the title as a second heading (fixes B2 I10).
  • The primary action names where it goes: “Back to My courses”, “Browse experiments”.
  • Never show route names, role codes, status codes or technical causes.
  • “Paused” always adds “your work is kept”. “Ended” states the date when known.
  • Whether an admin-written reason is shown on paused / ended pages is not decided (pause reason is open) — the template has room for one line if it is.
  • Confirmations (“Report sent”, “Feedback sent”, “Request sent”) use the same template with a reference where one exists.
