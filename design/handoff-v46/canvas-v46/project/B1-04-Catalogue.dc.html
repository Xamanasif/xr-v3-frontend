One record per experiment
LD-2: one row per published Experiment with its published format chips. The F21 / F33 catalogue split is retired. Unpublished experiments never appear.
Row
Thumbnail (concept artwork, decorative) · course code + name · title (link covering the row) · one-line summary · “Available in” formats.
Toolbar
The corrected Batch-0 toolbar: search grows, Sort keeps its width, Filters button only where the side panel is hidden (< 1024 px).
Filters
Engineering area · Course · Format, each with live counts. Applied immediately; each becomes a removable chip; Clear all filters resets everything.
Sort
Default order · Title A–Z · Course code. (“Canonical order” renamed “Default order”.) Order once a course has more than three experiments is OPEN.
Views
All experiments ↔ By area. Same results, same filters.
Selection marker
Rows already in the visitor’s selection show “In your selection” (see board B1-06 flow).
