What changes and why · catalogue details · delivery (web link, package reference) · version label · current and proposed (changed fields only — the shared comparison component).
Send for academic review (DL-1)
Needs a reason, a new version label, and at least one change. “The live version 1.2 doesn’t change until it is released.”
Withdraw (DL-2)
Reason required. Offered while the update is a draft, returned or in academic review; whether withdrawing needs anyone’s agreement is open (D-09-12).
One open update per experiment
Further edits from the published experiment join this draft.
Always
Content Manager → Academic Reviewer → Super Admin (LD-4). No technical-only shortcut (D-09-9). “Publish” never appears on this path.
