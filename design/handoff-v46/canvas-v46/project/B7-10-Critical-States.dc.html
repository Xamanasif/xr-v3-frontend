Never confuseHow the screens keep them apart
Release vs PublishThe Super Admin releases approved corrections; only the Content Manager publishes new experiments. “Publish” never appears on a Super Admin screen.
Hold vs Lift hold vs ReleaseHold keeps the live version; Lift hold only returns the correction to “waiting for your decision”; only Release changes what is live.
Pause vs EndPause is reversible with a reason and keeps everyone’s work; an ended plan returns only through a renewal request.
Reminder due vs sent“Reminder due” is a status. Nothing on these screens sends anything.
Override vs editAn override moves a stuck, non-published record’s status with a reason. Nothing edits content; Published is never a target.
Withdraw scope vs remove personWithdrawing a scope keeps the role holder and the reason; it can be restored.
