State sharing — canvas vs product

What the canvas proves, and what the real frontend must add.Each flow board shares ONE record between its own frames, and a board control can restart it. Separate boards never share state: the Faculty boards do not know what a Student did on another board. In the React · Next.js build, Claude Code implements one shared application state (records REQ, INST, ACC, SACC, RUN, FB, ASMT / ATT, DTR, SUB, EXP, UPD …) behind mock services, so every role sees the same record change — that cross-board behaviour is a build requirement, not something the canvas demonstrates.
