Question
“Who teaches which courses?” One table + one focused panel.
Layout
The panel sits beside the table (≈ 28 %) only from 1,060 px of content, where all four table columns and the row action fit. Below that it moves under the table as one compact form row (two selects + Assign course); on phones the fields stack. Row actions (“Assign a course”) and course codes never wrap or truncate.
Scope
Assigning ME ZG523 to Dr S. Ranganathan (FMAP-0021) is what later scopes his Faculty workspace (FA-F1 / FA-F2, Batch 4). Faculty courses never give students access.
Courses offered
Courses in the institution’s content access. Inactive faculty can’t be chosen.
Warning
Removing the last faculty member of a course with written answers waiting warns before confirming (IA-F6). The count comes from marking (Batch 4) — sample here.
