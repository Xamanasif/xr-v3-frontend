Accessibility at every width

CheckHow Batch 4 meets it
Text sizeBody 16 px; secondary 14–15 px; question text 17–18 px. Format chips keep the Batch-0 12–13 px code label next to words.
ContrastBatch-0 colour pairs only (≥ 4.5 : 1). Status is never colour alone: right / wrong marks carry an icon and words (“2 of 2 marks”).
KeyboardNative radios, checkboxes, inputs, selects and buttons. Dialogs (submit, confirm marks, delete) take focus and return it; error summaries take focus and link to each field; Next unanswered moves focus to the question.
AttemptEach question is a fieldset with a legend (or a labelled textarea); the review strip names each question “answered / not answered”; saving is announced (role=status); a failed save is announced (role=alert). No timer.
TargetsButtons ≥ 44 px (small 36 px); review-strip links and choice rows ≥ 44 px — above the 24 × 24 px WCAG 2.2 AA minimum.
ReflowNo horizontal page scroll at 375 px (script-checked on every Batch-4 board); tables become labelled rows; the tab bars scroll.
Consistent helpHelp stays at the sidebar foot (WCAG 3.2.6). The focused attempt keeps its way out in the same place on every width.
MotionOnly the Batch-0 spinner and the details chevron; both respect reduced motion.
