Question
“Which device is authorised for my headset formats, and can I move it?”
Chain
Student requests → Institute Admin forwards (IA-18 / IA-19, B3-09) → BITS approves (SA-18 / SA-19, B3-11). The same record DTR-0018 on every screen: With your Institute Admin · Forwarded to BITS · Approved.
Form
Free-text device fields (T-32): New device (required) and an optional note. Which other fields are needed is OPEN (D20b) — none were added.
Not designed
Decline / a Declined state (T-32 / D20a — WAIT); a device registry (D20b); notifications (T-34) — status shows in the product only.
One request at a time
While a request is open, its status replaces the Request button. Whether a second request may be opened is not decided — the design does not offer it.
