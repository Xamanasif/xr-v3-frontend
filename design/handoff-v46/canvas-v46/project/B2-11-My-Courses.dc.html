Courses and experiments come from Rahul’s grants (SACC-0310). An experiment the institution holds but hasn’t given him never appears as available; opening its address shows the “isn’t available to you” page.
Course rows: access only
A course row says what was given — “1 experiment given to you · WEB and VR available” — never a course- or experiment-level progress verdict such as “not started yet” or “in progress”.
Per format, in words
Progress appears only per format, on the experiment row and in the hub (“WEB not started · VR not started”). No percentage, no experiment-level “completed”, no unlocking or pass rules.
Course code
Institution code when the institution has added one (MEC-523), otherwise the BITS code — Student-facing code is OPEN (T-17).
