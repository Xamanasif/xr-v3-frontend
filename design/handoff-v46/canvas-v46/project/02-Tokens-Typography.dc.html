Icon sizing and working icon set

B2 had no navigation icons. A collapsed sidebar needs them, so Batch 0 adds a small stroke set on a 24 px grid. It is a working set — swappable — and an icon is always paired with a visible label or an accessible name.

Sizes
16 · inside status chips and inline errors · stroke 2
20 · default: nav, buttons, menus · stroke 1.75
24 · empty and message pages · stroke 1.75

Round caps and joins. currentColor only — icons inherit text colour, never carry meaning alone.

Motion principles

Motion explains a change of place or state. It is short, quiet and never needed to understand anything.

Durations
120 ms
Hover, colour, focus
200 ms
Menus, tooltips, tabs
280 ms
Drawer, dialog, banner

Easing cubic-bezier(.2, 0, 0, 1); colour changes are linear.

What moves
  • The drawer slides in from the left.
  • Dialogs fade and settle (scale .98 → 1).
  • Menus and tooltips fade.
  • Loading skeletons shimmer gently.
What never moves
  • No auto-advancing carousels.
  • No parallax or scroll-driven runways inside workspaces.
  • No looping decoration.
  • Reduced motion: every transition is instant and shimmer stops.
