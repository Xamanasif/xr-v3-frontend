Page archetypes AR-1 to AR-5

Structural patterns — hierarchy, density, composition and responsive behaviour — not templates to stamp. Each example uses real product content so the structure can be judged, and is labelled as a foundation pattern example: it does not approve the later-batch screen it resembles.

AR-2 · used by catalogue, queues, people, content lists

List / queue — “Which one do I open next?”

Structure
Header (+ primary action if the role creates) · search + ≤ 2 filters, more in a panel · rows that always link · result count.
Rules
Status in words. No count that cannot be opened. Sort stated in the header row.
Responsive
Below 760 px of content width the table becomes stacked rows with labels; filters move into a sheet.
State shown
Normal, and filtered to nothing.

AR-3 · used by institution, student record, experiment record, request status

Record detail — “What is this, and where is it now?”

Structure
Back link · ID · title · status in words · one next action · full-width sections stacked · history last.
Rules
Never two dense columns. Facts said once. Read-only says who has it now.

Sections stack unchanged; key–value lists become label-over-value below 600 px.
State shown
Read-only while with another role (no action).
