Steps
Course and description → Formats and delivery → Preview and documents → Check and submit (AR-5). One section per step, single column. Save draft at every step; the same editor edits a draft and revises a returned experiment.
Course
Labelled “Course”. Only the courses assigned to Northline Simulation Studio are listed (sample: ME ZG523). BITS / WILP sets them (Super Admin · Platform roles — Batch 7).
Name
Required and must not repeat another experiment’s name (checked on Continue).
Field set
Summary, description and version are the prototype field set; the catalogue schema and who maps an experiment to a course stay open (T-29).
Not here
Learning outcomes — the Academic Reviewer adds them; the Vendor sees them read-only. No “Propose an update”, no “Add a format” (LD-4).
