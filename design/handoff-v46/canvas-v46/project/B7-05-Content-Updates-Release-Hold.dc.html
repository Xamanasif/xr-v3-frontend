Question
“Which corrections are waiting, and should this one go live?”
Release (DL-1)
Version 1.3 replaces 1.2 for everyone — the public catalogue and every institution using it. History keeps 1.2 and every decision.
Hold (reason)
Version 1.2 stays live; the Content Manager sees the reason. Batch-0 Dialogs (board 10) puts hold with the reason-required dialogs; the Register lists it as DL-1 — recorded as OD-B7-01.
Lift hold (DL-1)
Returns the update to “Waiting for your decision”. It never releases anything by itself (no automatic release).
Not decided here
What else a hold affects, and whether a held update blocks later corrections, are open (T-28) — the screens say so and invent nothing.
Never
The word “Publish” does not appear on this path. The Super Admin never edits the correction. Release grants or changes no institution’s access.
