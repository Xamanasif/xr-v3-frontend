What it is
A request for draft questions from material the Faculty chooses (the experiment’s lab brief, or pasted text).
Review first
Every draft is tagged “Draft — needs your review” and “Drafted with assistance”. Nothing enters the bank until the Faculty adds it (T-23). Discarded drafts leave no trace in the bank.
Not designed
Which service drafts the questions, how deep the assistance goes, and suggested marks when marking (T-23 / A-18 / R16 — open). No provider is named anywhere.
Failure
Drafting can fail: “Nothing was added to your bank. Try again.”

Steps
Choose a file (template) → check rows (errors block, warnings don’t) → confirm → result. Same pattern as Import students (B2-07).
Format
CSV with the template’s ten columns. XLSX and the final column schema are open (T-24 · D5).
Commit
All or nothing while any row has an error — an interim rule, labelled; valid-rows-only is the other option still open (T-24).
Result
Questions go into the bank only. They are never added to an assessment by importing.
