Two codes, two owners
BITS course code ME ZG523 — set by BITS (Content Manager), read-only here. Your course code — Godavari’s own field, optional semester alongside (IA-16, M-2).
Who sees it
Students and faculty at the institution see the institution’s code with the course name (IA-16). Which code the Student workspace shows is still OPEN (T-17); Batch 2 shows the institution code when it exists and the BITS code until then.
Validation
Only one rule is designed: a semester needs a code. No code format is invented.
