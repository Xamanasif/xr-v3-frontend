Shape
AR-6 focused task: a slim bar with the way out, the save state and the account; no sidebar. One page of questions, a review strip, one Submit.
Questions
Three types only — multiple choice (one correct), true or false, written answer (T-22). Marks per question as set by the Faculty.
Saving
Every answer saves as it changes. A failed save says so in the bar and offers Try again; nothing already saved is lost.
Submitting
Never automatic and no timer. Submit opens DL-1: “You can’t change your answers after submitting.” Unanswered questions are named in the same dialog; the student may still submit.
Leaving
The way out (Shell-and-Tube Heat Exchanger) keeps every saved answer; coming back continues the same attempt (“Continue attempt” on ST-12).
Not shown
Marking guidance for the written answer (Faculty only — open question), any score, any countdown.
Same record
The submitted attempt ATT-0450 is the one Faculty see in Submissions (B4-06) and in Marking (B4-09).
