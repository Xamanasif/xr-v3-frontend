Accessibility at every width

CheckHow Batch 3 meets it
Text sizeBody 16 px; secondary 14–15 px; nothing essential below 14 px. Format chips keep the Batch-0 12–13 px code label next to words.
ContrastBatch-0 colour pairs only (≥ 4.5 : 1). Status is never colour alone: every chip has words.
KeyboardNative buttons, links, inputs, radios and selects. Dialogs move focus to their action and return it; error summaries take focus and link to fields; opening / sending moves focus to the result.
Rating scaleEach statement is a fieldset with a legend; five labelled radio options (1 Strongly disagree … 5 Strongly agree); the selected option is shown by fill and text, not colour alone; full-width rows below 520 px for touch.
TargetsButtons ≥ 44 px (small 36 px); scale options ≥ 48 px high — above the 24 × 24 px WCAG 2.2 AA minimum.
ReflowNo horizontal page scroll at 375 px (script-checked on every Batch-3 board); tables become labelled rows.
Consistent helpHelp stays at the sidebar foot and in the account menu (WCAG 3.2.6); “Report a problem” on format pages opens the same Help.
MotionOnly the Batch-0 spinner and the details chevron; both respect reduced motion.
