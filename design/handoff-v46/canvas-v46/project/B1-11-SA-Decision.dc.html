Layout (AR-4, B2 A2 kept)
Details ~72 % · decision panel ~28 % (sticky). Below 860 px of content the panel moves under the details, with Go to decision at the top.
Details
Summary facts · organisation and contact person · what they’re asking for (requested vs published formats, licences, term) · existing access · requester’s message · history · “What happens after you decide” as help (replaces B2’s chain diagram).
Decisions
Approve request · Approve a smaller scope (difference + reason recorded) · Request more information (reason). Internal / external is set here, at approval, for a new institution (T-04).
Four separate events
Institution record (created at the first approval of a new institution) · request approval (this decision) · payment confirmation (external only, not on this page) · institutional access activation (internal: on approval; external: only after payment is confirmed). Help, confirmation, panel and history all use these four words.
Before approval completes
Internal or external must be chosen — approval can’t finish with “Not set yet” (the summary keeps showing “Not set yet” until it does). Internal → no payment, access activated. External → Approved — payment required, access not active. Smaller scope needs a real difference and a reason. Request more information needs a reason.
Confirmation
States what happens for the chosen route only, event by event, and what does not happen yet.
Not here
Decline (T-02 / R21) · manual “mark paid” (R06) · creating an institution directly · amending a plan (D8) · undefined statuses · technical audit panels.

    Institution record

    Created when you approve the first request from a new institution. A record is not access.

  2. 2

    Request approval — your decision on this page

    External: the request becomes Approved — payment required. Internal: approved with no payment step. Smaller scope: the requester sees the difference and your reason.

  3. 3

    Payment confirmation — external only

    Happens after the requester pays. It is not recorded on this page.

  4. 4

    Institutional access activation

    Internal: when you approve. External: only after the payment is confirmed. Activation creates the access plan the institution administrator sees. Students get access only when that administrator gives it.

Request more information keeps the request open; none of the four events happen until it is approved.
