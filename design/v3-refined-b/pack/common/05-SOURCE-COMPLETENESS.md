# What this package actually contains

## Received from the owner

Nine current V3 source files: design-tokens.json, canvas.json, core.css, rb.css, rb-kit.css, SA01.dc.html, SA02.dc.html, IA01.dc.html and IA02.dc.html. Also HANDOFF(1).md, preserved as HANDOFF-original.md.

SA02.dc.html contains both Requests and Request Decision. A missing separate SA03 base file does not mean its principal layout and decision component are absent.

The original V3 canvas index lists state/width wrappers, Main, Kit and an IA01-calm file that were NOT included in the individual upload. All four component files reference support.js; the current V3 runtime was NOT uploaded. Therefore these individual files are an adequate reference foundation but NOT the complete 51-board runnable export.

Do not import that incomplete canvas index as a completed new project. Read it for coverage, build a new index for the files you actually create, and use the design host's supported runtime. Needed responsive/state wrappers can be newly authored from the supplied component properties and handoff; label them new derivatives, never recovered original files. Do not claim byte-identical recovery of missing files.

The v46 and V1 archives include a historical support.js. It is provided in reference paths only; compatibility with the latest V3 components has not been established here. Do not silently treat it as the latest runtime, and never ship the design runtime in the React app.

## Older references

The `XR Platform Design V2 Directions.zip` archive is the earlier File-35/V1 visual reference despite its historical filename. The later v46 archive is the full screen register and behavior source. Preserve original bytes and distinguish their purposes.

Original V1 role references cover a few representative screens, not all 123. V3 source covers five screen IDs, not entire Super Admin or Institute Admin roles. The latest application repository is NOT included in these design packs; Code must use the actual local checkout.

## Packaging subsets

Each role pack includes all v46 boards named for its owned IDs, relevant supporting boards, shared styles, handoff JSON and selected V1 role sources. Full indexes can mention out-of-role files not included in that subset; do not confuse those reference-only links with missing owned deliverables.

Raw source files keep their source terminology, comments and historical instructions. The common owner-decision document clarifies what is current and what is historical. No old content has been silently rewritten to look authoritative.

## Official logo and fonts

The WILP image has not been supplied. Its appearance in old screenshots does not establish that the binary is in this package. Retain the reserved slot. Do not invent a crest or make logo delivery a blocker for role layout work.

No font binaries are distributed in these packs. Use Public Sans via the existing approved font loading arrangement or an available legitimate resource. Record font-load failures when comparing layout; do not change the design font to hide a rendering problem.

## Verification boundary

This coordination package verifies ownership, file presence, hashes and ZIP structure. It does not independently certify the supplied design's rendered UI, the reported test counts, or the state of the user's Mac repository.
