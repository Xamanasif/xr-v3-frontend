# XR Learning Platform - coordinated V3 delivery

This package contains ready-to-use complete-role Claude Design instructions, their source references and the Claude Code integration instructions. It is not a new design artifact or a completed application.

## For Claude Design

Choose the role's ZIP from `packs/`. Each is self-contained: current shared V3 sources, common rules, exact role scope, relevant V1 references and v46 source boards. Do not upload every pack into every conversation.

Create a separate design session for that role. Upload its one reference ZIP, then copy the contents of its `START-TASK.md` into the message box. The same text is in the matching file under `prompts/`. Keep the original frozen projects untouched.

The central rules are already part of each assignment. You do not need to paste nine separate rules documents manually. If Claude cannot extract a ZIP, unzip it locally and provide the same folder's files using its supported file/folder mechanism. Do not authorize designs based only on filenames when sources cannot be read.

## For Claude Code

Unzip `packs/XR-V3-Claude-Code-Integration-Pack.zip` into a separate local reference folder outside the protected checkout. Give the Code session access to that folder and the existing frontend. Paste `10-Claude-Code-V3-Integration-Controller.md`.

That starts safe foundation preparation only. When a complete role has been designed and owner-approved, supply its exported source folder and paste `11-Claude-Code-Complete-Role-Intake.md` in the same integration workflow.

Use `12-Claude-Code-Final-Cross-Role-Verification.md` when the imports are complete. Do not run `13-HOLD-ONLY-V1-Landing-Fidelity-Integration.md` without its separate owner authorization.

## Boundaries

- Refined Direction B is the shared interface; no independent palette/layout system per role.
- Complete-role deliveries, not overview-only batches.
- Preserve current functional mappings, states, permissions and local-demo capabilities.
- V1 Public Landing is locked and not part of redesign work.
- No real backend, remote push or deployment; no new Codex audit cycle.
- Official WILP logo is pending; reserve its slot without inventing it.

Read EXECUTION-PLAN.md for the launch order, SCREEN-OWNERSHIP.md for exact coverage and common/05-SOURCE-COMPLETENESS.md for reference limitations.
