# Owner-approved V3 role exports (read-only)

Each folder here is one owner-approved complete role export, copied byte for byte from the source
archive the owner supplied, under `design/v3-refined-b/roles/<ROLE>-<revision>/`. Never edit,
normalise, reformat, regenerate or re-export a file under a role folder. A folder whose export
ships its own `SHA256SUMS.txt` is checked with `shasum -a 256 -c SHA256SUMS.txt` from inside it;
an export that ships none is checked against the list recorded at intake beside its folder
(`shasum -a 256 -c ../<folder>.SHA256SUMS.txt` from inside it), so nothing is added to the export. The `.dc.html` sample records, preview state machines and preview-only classes in an export
are not domain logic and never product UI (`ROLE-INTAKE-REQUIREMENTS.md` in `v2/docs/v3/`).
